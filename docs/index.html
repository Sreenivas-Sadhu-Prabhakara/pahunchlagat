Why the GST toggle matters

Get it backwards and every cost sheet is off by the GST rate. A registered shop recovers GST as input credit — it is not a cost. A composition or unregistered shop cannot — so GST is added to the cost base.

Landed = goods + (GST if unregistered) + freight + coolie + transport, spread over units net of wastage %.

Flutter → Go → PostgreSQL; the Go middleware keeps a printable history of cost sheets.
